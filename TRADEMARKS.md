# Names and marks

The Apache License 2.0 that covers this software grants **no rights in the
project's names, logos or marks** (section 6). This file says how they may be
used.

`sayfirst` is the project's public name. The rules below apply to that name and
its logo once filed, and to the names of the project's own packages and
command. The marks are held by the lead in person; this file names a different
holder if that changes.

## You may

- state that your software uses, integrates with or is compatible with
  `sayfirst`, truthfully;
- redistribute unmodified releases under the project's name;
- refer to the project by name in articles, talks and documentation.

## You may not

- use the name or logo as, or as part of, the name of your own product,
  service, package or organisation;
- use them in a way that suggests endorsement by, or affiliation with, the
  project or its lead;
- distribute a modified version under the project's name; call it something
  else and say what it is based on.

## Package indexes

Only the maintainers publish packages under the project's name on public
indexes. A fork publishes under its own name.

Questions about a use not covered here go to the lead.
